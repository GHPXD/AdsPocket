# Fontes de pesquisa — 1.2.0

O registro `MiningSourceRegistry` fornece identidade, categoria, URL oficial, capacidades, necessidade de conta, acesso pago e formatos locais. API disponível, países e última verificação automática permanecem desconhecidos quando não verificados. Nenhuma credencial é exigida pelo AdsPocket.

| Fonte | Categoria | Acesso nesta versão |
|---|---|---|
| Meta Ads Library | Anúncios | WebView existente e filtros locais do assistente |
| Google Ads Transparency / TikTok Creative Center | Anúncios | Site oficial, consulta copiada para uso nos controles do provedor |
| Google Search / Trends / Reddit | Demanda e dores | Consulta na URL pública do site oficial |
| Reclame Aqui / Mercado Livre | Dores e produtos | Site oficial, consulta copiada |
| Semrush / Similarweb | Demanda | Site oficial; funções podem exigir assinatura/conta |

Todos são acessos assistidos. Não há API conectada, importação de métricas, monitoramento automático nem bypass de login. JSON importa registros de pesquisa no formato do AdsPocket; não é um adaptador para relatórios nativos desses provedores. CSV de relatórios, radares e marketplaces integrados permanecem na fase 2.
